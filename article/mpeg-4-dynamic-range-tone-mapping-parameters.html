MPEG-4 Dynamic Range Tone Mapping Parameters

Dynamic range tone mapping in MPEG-4 streams (including MPEG-4 Part 10 / AVC / H.264) allows displays with varying luminance capabilities to correctly render video content without clipping highlights or crushing shadow details. This article breaks down the essential syntax elements, Video Usability Information (VUI), and Supplemental Enhancement Information (SEI) messages embedded within the MPEG-4 bitstream that dictate dynamic range adjustments and tone mapping.

Tone Mapping Information SEI Message

The primary mechanism for direct tone mapping control within an MPEG-4 bitstream is the Tone Mapping Information SEI message. This message provides the decoder and display processor with specific mapping functions to convert between bit depths or dynamic ranges (such as mapping HDR to SDR or higher-bit-depth sources to legacy displays). Key parameters include:

  • tone_map_id: An arbitrary identification number assigned to a specific tone map instance.
  • tone_map_cancel_flag: A boolean flag indicating whether previous tone mapping persistence is canceled.
  • tone_map_repetition_period: Dictates the persistence of the tone map across subsequent frames.
  • coded_data_bit_depth & target_bit_depth: Define the bit depth of the encoded stream and the intended target output bit depth after mapping.
  • tone_map_model_id: Defines the mathematical model used for tone mapping. The models determine which additional parameters follow:
    • Model 0 (Linear Mapping): Uses min/max thresholds to perform simple clipping and scaling.
    • Model 1 (Sigmoidal / Thresholds): Uses parameters defining clipping thresholds and sigmoid curves.
    • Model 2 (Lookup Table): Provides explicit lookup table (LUT) values for arbitrary mapping curves.
    • Model 3 (Piecewise Linear Mapping): Defines coordinate pairs (knee points) with segment slopes (coded_pivot_value and target_pivot_value).
    • Model 4 (Custom/Transform Curve): Uses specific parametric functions, including scale factors and exponent parameters (such as gamma parameters).

Video Usability Information (VUI) Parameters

Embedded within the Sequence Parameter Set (SPS), VUI parameters establish the baseline colorimetry and dynamic range characteristics of the video signal before mapping occurs:

  • transfer_characteristics: Defines the Electro-Optical Transfer Function (EOTF) of the source video (e.g., BT.709 for SDR, BT.2084/PQ, or BT.2100/HLG for HDR).
  • colour_primaries: Specifies the chromaticity coordinates of the source color primaries (e.g., BT.709, DCI-P3, BT.2020).
  • matrix_coeffs: Identifies the matrix equations used to derive luma and chroma from RGB primaries.

Static Metadata SEI Messages

Modern high dynamic range extensions for MPEG bitstreams use additional static metadata SEI messages to guide tone mapping engines on the display:

  • Mastering Display Colour Volume SEI: Contains max_display_mastering_luminance and min_display_mastering_luminance to specify the exact peak and black luminance boundaries of the monitor used during color grading.
  • Content Light Level Information SEI: Provides max_content_light_level (MaxCLL) representing the brightest single pixel and max_pic_average_light_level (MaxFALL) representing the highest average frame luminance across the entire stream.

Dynamic Metadata (SMPTE ST 2094 / User Data Registered SEI)

For scene-by-scene or frame-by-frame adaptive tone mapping, MPEG streams carry dynamic metadata within User Data Registered SEI (ITU-T T.35) payloads. These parameters include:

  • Target Display Luminance: The peak and minimum brightness of the target reference display.
  • Percentile Luminance Distribution: Statistical distribution of luminance within a specific scene (e.g., 1%, 50%, 99% max values).
  • Bezier Curve Control Points (Knee Points): Spline parameters that tell the tone mapping engine how to compress highlight luminance while preserving mid-tone brightness dynamically for specific scenes.
