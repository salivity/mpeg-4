MPEG-4 AVC Inter-View Prediction in 3D Video

MPEG-4 Advanced Video Coding (AVC), formally known as ITU-T H.264, processes stereoscopic 3D video using its Multiview Video Coding (MVC) extension (Annex H). This article examines how MPEG-4 AVC utilizes inter-view prediction to eliminate redundancy between the left-eye and right-eye views, drastically reducing overall bitrates compared to dual independent streams while maintaining backward compatibility with legacy 2D hardware.

The Base View and Dependent View Structure

In stereoscopic video compression, MPEG-4 AVC designates one video channel (typically the left eye) as the Base View and the secondary channel (the right eye) as the Dependent View.

  • Base View: Encoded using standard H.264/AVC syntax without any inter-view dependencies. Any standard 2D AVC decoder can decode and display this stream normally.
  • Dependent View: Encoded using inter-view prediction references taken from the decoded base view at the same time instance, along with standard temporal references from its own timeline.

Inter-View Prediction Mechanism

Inter-view prediction leverages the high spatial correlation between the two cameras recording the same scene from slightly offset horizontal angles. MPEG-4 AVC adapts its existing motion-compensated prediction framework to perform disparity-compensated prediction:

  1. Reference Picture List Expansion: In standard AVC, reference picture lists (List 0 and List 1) store temporally neighboring frames (past and future frames in the same view). In MVC, the reference picture lists of the dependent view are modified to include reconstructed frames from the base view captured at the exact same time point.
  2. Disparity Estimation and Compensation: Instead of calculating motion vectors across time, the encoder calculates disparity vectors between the views. The disparity vector represents the horizontal and vertical shift between corresponding objects in the left and right perspectives.
  3. Macroblock-Level Mode Decision: For every macroblock in the dependent view, the encoder dynamically evaluates whether to use:
    • Intra-prediction: Spatial prediction within the current frame.
    • Temporal inter-prediction: Motion compensation using previous or future frames within the dependent view.
    • Inter-view prediction: Disparity compensation using the co-temporal frame from the base view.
    • Inter-view B-prediction: Bi-directional prediction combining both a temporal reference and an inter-view reference simultaneously.

Reference Management and Synchronization

To ensure stable decoding without transmission errors cascading between views, MPEG-4 AVC imposes strict synchronization rules:

  • Anchor Pictures: Special frames where all views only use inter-view prediction (no temporal prediction from previous frames). Anchor frames correspond to IDR (Instantaneous Decoder Refresh) frames in the base view and allow random access into the 3D stream.
  • Non-Anchor Pictures: Standard frames that can use both temporal and inter-view prediction.

Compression Efficiency

Because human eyes receive nearly identical scene backgrounds, lighting, and textures, inter-view prediction removes immense amounts of cross-view data duplication. This allows MPEG-4 AVC to deliver a complete stereoscopic 1080p 3D video stream using only roughly 50% more data than a single 2D video stream, representing a 20% to 30% bitrate saving over transmitting two independent AVC streams.
