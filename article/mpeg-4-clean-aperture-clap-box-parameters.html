MPEG-4 Clean Aperture (clap) Box Parameters

The Track Clean Aperture box (clap), defined in the ISO Base Media File Format (ISO/IEC 14496-12) and Apple QuickTime specifications, defines the precise visible boundaries of a video frame to crop out edge artifacts, digital blanking, or distortion. This article details the specific parameters stored within the clap atom and explains how these fractional values determine the size and alignment of the active viewing area.

Core Parameters of the 'clap' Box

The clap atom stores four main fractional dimensions. Because floating-point representation can introduce rounding errors, each parameter is stored as a rational number composed of a 32-bit numerator and a 32-bit denominator:

  1. Clean Aperture Width (cleanApertureWidthN / cleanApertureWidthD)

    • Definition: Specifies the exact horizontal width of the clean aperture in display pixels.
    • Components: Stored as an unsigned 32-bit integer numerator (cleanApertureWidthN) and an unsigned 32-bit integer denominator (cleanApertureWidthD).

  2. Clean Aperture Height (cleanApertureHeightN / cleanApertureHeightD)

    • Definition: Specifies the exact vertical height of the clean aperture in display pixels.
    • Components: Stored as an unsigned 32-bit integer numerator (cleanApertureHeightN) and an unsigned 32-bit integer denominator (cleanApertureHeightD).

  3. Horizontal Offset (horizOffN / horizOffD)

    • Definition: Defines the horizontal offset of the center of the clean aperture relative to the center of the encoded video frame.
    • Components: Stored as a signed 32-bit integer numerator (horizOffN) and an unsigned 32-bit integer denominator (horizOffD). A value of zero places the clean aperture directly at the horizontal center, positive values shift the aperture to the right, and negative values shift it to the left.

  4. Vertical Offset (vertOffN / vertOffD)

    • Definition: Defines the vertical offset of the center of the clean aperture relative to the center of the encoded video frame.
    • Components: Stored as a signed 32-bit integer numerator (vertOffN) and an unsigned 32-bit integer denominator (vertOffD). A value of zero places the clean aperture directly at the vertical center, positive values shift the aperture downward, and negative values shift it upward.

How Playback Decoders Apply These Parameters

When a media player or decoder processes a video track containing a clap box:

  • It reads the encoded pixel dimensions from the video sample description (stsd).
  • It calculates the active visible rectangle using the rational width and height values.
  • It aligns the center of the calculated rectangle with the center of the stored frame, modified by the fractional horizontal and vertical offset values.
  • The content outside this defined boundary is cropped during rendering, ensuring only the clean, intended picture area is displayed.
