MPEG-4 Timed Text Styling and Positioning

MPEG-4 Timed Text (ISO/IEC 14496-17) specifies presentation styling for subtitles and captions by combining default track-level parameters with sample-level overrides. This system enables precise control over font appearance, text sizing, color attributes, and screen positioning using dedicated data structures embedded directly within the MP4 container.

Architecture of Timed Text Styling

MPEG-4 Timed Text separates styling into two main layers: default global definitions and inline sample modifiers.

Global defaults are defined inside the Sample Description box (typically the tx3g atom). This atom defines the default font family, text box dimensions, alignment, and background/foreground colors.

When a specific subtitle requires distinct formatting, the text sample includes inline Modifier Boxes that alter the presentation for specific character ranges or entire samples without modifying the global track defaults.

Screen Positioning and Layout

Positioning is determined through a hierarchy of bounding boxes:

  1. Track Header (tkhd) and Media Dimensions: The overall coordinate space is defined by the width and height of the timed text track, typically aligned with the underlying video canvas.
  2. Text Display Box (BoxRecord): The BoxRecord specifies the rectangular area inside the track space where the text is rendered. It is defined by four 16-bit integer coordinates: top, left, bottom, and right.
  3. Text Alignment: Inside the display box, text is positioned using horizontal and vertical justification flags (e.g., left-aligned, centered, right-aligned, top-aligned, or bottom-aligned).

If dynamic movement or custom placement is needed for a specific sample, an inline tbox (Text Box) modifier box overrides the default BoxRecord.

Font Sizing and Typeface Attributes

Typography is managed through font tables and style records:

  • Font Identification: The tx3g description contains a FontTableBox (ftab), which maps numerical font-ID values to specific font family names (such as "Arial" or "Helvetica").
  • Font Size: Size is declared as an unsigned 8-bit integer representing the point size relative to the track's coordinate resolution.
  • Face Style Flags: Text attributes are set via an 8-bit bitmask:
    • Bit 0: Bold
    • Bit 1: Italic
    • Bit 2: Underline

Color and Transparency Definitions

MPEG-4 Timed Text uses 32-bit RGBA color representation (8 bits each for Red, Green, Blue, and Alpha/transparency channels):

  • Background Color: Defined in the tx3g box as a 32-bit RGBA value, determining the fill color of the text display box. An alpha value of 0 renders the background completely transparent.
  • Text (Foreground) Color: Specified in the default sample description and within individual style records. The RGBA structure allows full opacity, semi-transparency for overlays, or fully transparent text effects.
  • Highlight Color: Highlight and karaoke effects utilize modifier boxes (krok, hlit) that specify secondary RGBA colors applied over time or across specific character offsets.

Dynamic In-Sample Styling (StyleRecord)

To format partial text strings (such as italicizing a single word or changing text color mid-sentence), the sample payload appends a StyleBox (styl). This box contains one or more StyleRecord structures:

  • startChar and endChar: 16-bit indexes marking the character range.
  • font-ID: The font reference from the font table.
  • face-style-flags: Bold, italic, or underline bitmask.
  • font-size: Point size for the selected range.
  • text-color-rgba: 32-bit color applied to the range.

This structured format ensures that media players render synchronized subtitles with uniform layout, exact dimensions, and standardized typographic properties across compliant playback platforms.
