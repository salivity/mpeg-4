MPEG-4 Sub-Pixel Interpolation in Motion Estimation

MPEG-4 video compression improves motion estimation accuracy by calculating pixel values at fractional grid positions, specifically at half-pixel (half-pel) and quarter-pixel (quarter-pel) intervals. This article explains the mathematical formulas and filtering techniques MPEG-4 utilizes to interpolate these sub-pixel luminance and chrominance values from the surrounding integer-pixel grid during motion compensation.

Integer Grid and Fractional Notation

Let the reconstructed integer luminance samples be denoted as \(S(x, y)\), where \(x\) and \(y\) represent integer spatial coordinates on the reference frame. Sub-pixel positions are referenced as offsets relative to the integer coordinates:

  • Half-pixel offsets: \(S(x + 0.5, y)\), \(S(x, y + 0.5)\), and \(S(x + 0.5, y + 0.5)\).
  • Quarter-pixel offsets: Positions with increments of \(\pm 0.25\) along either axis.

Half-Pixel (Half-Pel) Interpolation

In standard MPEG-4 Part 2 (Simple and Advanced Simple Profiles), half-pixel positions are computed using bilinear interpolation with a rounding control parameter (\(rnd \in \{0, 1\}\)) to avoid rounding drift across sequential frames.

  1. Horizontal Half-Pixel: \[S(x + 0.5, y) = \left\lfloor \frac{S(x, y) + S(x + 1, y) + 1 - rnd}{2} \right\rfloor\]

  2. Vertical Half-Pixel: \[S(x, y + 0.5) = \left\lfloor \frac{S(x, y) + S(x, y + 1) + 1 - rnd}{2} \right\rfloor\]

  3. Diagonal Half-Pixel: \[S(x + 0.5, y + 0.5) = \left\lfloor \frac{S(x, y) + S(x + 1, y) + S(x, y + 1) + S(x + 1, y + 1) + 2 - rnd}{4} \right\rfloor\]

The rounding control parameter \(rnd\) alternates between \(0\) and \(1\) on a frame-by-frame basis, governed by the bitstream header.

Quarter-Pixel (Quarter-Pel) Interpolation

For high-precision profiles (such as MPEG-4 Part 2 Advanced Simple Profile and MPEG-4 Part 10 / AVC), quarter-pixel interpolation is executed using a two-step process: high-order FIR filtering for half-pel positions followed by bilinear interpolation for quarter-pel positions.

1. Half-Pel Generation via 6-Tap Filter (MPEG-4 Part 10 / H.264)

Half-pel samples are generated using a 1D symmetric 6-tap FIR filter with weights \([1, -5, 20, 20, -5, 1]\).

For a horizontal half-pel sample \(b\): \[b_1 = S(x-2, y) - 5S(x-1, y) + 20S(x, y) + 20S(x+1, y) - 5S(x+2, y) + S(x+3, y)\] \[b = \text{Clip1}\left( \left\lfloor \frac{b_1 + 16}{32} \right\rfloor \right)\]

For the center diagonal position \(j\): The filter is applied vertically to the unclipped intermediate values \(b_1\) of six adjacent horizontal half-pel positions: \[j_1 = b_1(y-2) - 5b_1(y-1) + 20b_1(y) + 20b_1(y+1) - 5b_1(y+2) + b_1(y+3)\] \[j = \text{Clip1}\left( \left\lfloor \frac{j_1 + 512}{1024} \right\rfloor \right)\]

2. Quarter-Pel Refinement

Quarter-pel samples are then calculated by taking the average of adjacent integer and half-pel samples:

\[S(x + 0.25, y) = \left\lfloor \frac{S(x, y) + b + 1}{2} \right\rfloor\]

For samples situated between two half-pel positions diagonally: \[S(x + 0.25, y + 0.25) = \left\lfloor \frac{b + h + 1}{2} \right\rfloor\] where \(b\) is the horizontal half-pel and \(h\) is the vertical half-pel.

Chrominance Interpolation

Because color formats typically use 4:2:0 subsampling, an eighth-pel (or sixteenth-pel) resolution is required for chrominance channels. MPEG-4 evaluates chroma samples using linear weighting based on the fractional parts of the motion vector components:

\[S_c(x, y) = \left\lfloor \frac{(8 - dx)(8 - dy)A + dx(8 - dy)B + (8 - dx)dyC + dx \cdot dyD + 32}{64} \right\rfloor\]

Where:

  • \(A, B, C, D\) represent the surrounding integer chrominance samples forming a bounding square.
  • \(dx\) and \(dy\) represent the fractional motion vector offsets modulo 8.
