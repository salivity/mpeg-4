What Is MPEG-4 Audio Object Type 2 (AAC-LC)?

This article provides a technical definition of Audio Object Type 2 (AAC-LC) under the MPEG-4 Part 3 (ISO/IEC 14496-3) standard. It outlines the core architectural components, processing pipeline, and structural specifications that make AAC-LC the industry baseline for efficient digital audio encoding.

Technical Definition of Audio Object Type 2

In the MPEG-4 Part 3 standard (ISO/IEC 14496-3 Subpart 4), Audio Object Type 2 designates AAC Low Complexity (AAC-LC). It is a psychoacoustic-based, lossy perceptual audio coding scheme derived from the earlier MPEG-2 AAC standard (ISO/IEC 13818-7), optimized to provide high-fidelity audio reproduction with reduced memory requirements and computational complexity.

Within the MPEG-4 bitstream configuration syntax (AudioSpecificConfig), the 5-bit audioObjectType field with a binary value of 00010 (decimal value 2) signals decoders to instantiate the AAC-LC processing pipeline.

Architectural Components and Toolset

AAC-LC uses a transform-based coding architecture that analyzes and compresses raw audio signals using perceptual psychoacoustic modeling. Its core toolset consists of the following components:

  • Filterbank (MDCT): Converts time-domain audio samples into frequency-domain spectral coefficients using the Modified Discrete Cosine Transform (MDCT). It switches dynamically between a long block size (2048 samples, transforming to 1024 frequency coefficients) for high spectral resolution during stationary signals, and a short block size (256 samples, transforming to 128 coefficients) to prevent pre-echo artifacts during transient signals.
  • Temporal Noise Shaping (TNS): Applies linear prediction across spectral bins to shape the temporal distribution of quantization noise within each transform window, preventing noise from spreading outside of localized transient events.
  • Psychoacoustic Model: Evaluates masking thresholds (simultaneous and temporal masking) to determine the imperceptible noise threshold, guiding the quantization process to discard psychoacoustically redundant data.
  • Perceptual Noise Substitution (PNS): Replaces noise-like frequency subbands with a single energy parameter and a pseudo-random noise generator at the decoder, significantly reducing bitrate for ambient or unvoiced content.
  • Joint Stereo Coding: Employs Mid/Side (M/S) stereo coding to encode sum and difference signals between paired channels, as well as intensity stereo coding for higher frequency bands to optimize multichannel correlation.
  • Quantization and Entropy Coding: Applies non-uniform scalar quantization based on scale factors per scalefactor band, followed by 2D/4D Huffman coding to achieve lossless entropy compression of the quantized spectral data.

Distinctions Within the MPEG-4 Standard

Audio Object Type 2 intentionally excludes processing-intensive tools found in other MPEG-4 profiles to maintain low computational latency and lower hardware resource utilization:

  • No Backward Predictors: Unlike AAC Main (AOT 1), AAC-LC removes backward-adaptive linear prediction.
  • No Long Term Prediction (LTP): Unlike AAC LTP (AOT 4), AAC-LC does not utilize time-domain pitch predictors.
  • Foundation for Extended AOTs: AAC-LC serves as the mandatory core foundation for more complex objects, including High-Efficiency AAC (HE-AAC v1 / AOT 5), which adds Spectral Band Replication (SBR), and HE-AAC v2 (AOT 29), which adds Parametric Stereo (PS).

Technical Specifications

  • Sampling Frequencies: Native support from 8 kHz to 96 kHz.
  • Channel Configurations: Scalable from 1 (mono) up to 48 independent audio channels, as well as arbitrary multi-channel layouts using Program Config Elements (PCE).
  • Bitrate Range: Typically operated between 64 kbps and 320 kbps for stereo streams (with standard transparent fidelity achieved around 128 kbps to 192 kbps).
  • Frame Size: 1024 samples per frame per channel (or 960 samples per frame in specific broadcast modes).
