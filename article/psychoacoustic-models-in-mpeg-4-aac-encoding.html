Psychoacoustic Models in MPEG-4 AAC Encoding

MPEG-4 Advanced Audio Coding (AAC) achieves high-fidelity audio compression by eliminating perceptually irrelevant spectral data through psychoacoustic analysis. While early MPEG-1 standards introduced both Psychoacoustic Model 1 and Psychoacoustic Model 2, MPEG-4 AAC exclusively relies on an evolved implementation of Psychoacoustic Model 2 (often designated as the MPEG AAC Psychoacoustic Model) to compute dynamic masking thresholds and control quantization noise.

The Origins: Psychoacoustic Model 1 vs. Model 2

In the original MPEG-1 audio specifications (ISO/IEC 11172-3), the MPEG committee defined two distinct, non-normative psychoacoustic models for encoder development:

  • Psychoacoustic Model 1: A computationally lighter algorithm designed primarily for MPEG-1 Layer I and Layer II. It separates the spectrum into critical bands, classifies spectral components strictly as tonal or non-tonal (noise-like) based on local peaks, and applies fixed spreading functions to estimate the global masking threshold.
  • Psychoacoustic Model 2: A mathematically sophisticated, energy- and phase-based algorithm originally developed for MPEG-1 Layer III (MP3). Rather than relying on simple peak detection, it determines tonality through an unpredictability measure by comparing the current frame’s magnitude and phase against predictions derived from past frames.

Why MPEG-4 AAC Uses Psychoacoustic Model 2

MPEG-2 and MPEG-4 AAC standards (ISO/IEC 13818-7 and ISO/IEC 14496-3) abandoned Psychoacoustic Model 1 entirely in favor of an adapted, enhanced version of Psychoacoustic Model 2. The architecture of AAC—which replaces hybrid polyphase filterbanks with a pure Modified Discrete Cosine Transform (MDCT)—requires the high-resolution frequency analysis and tonality calculations that only Model 2 provides.

The specific psychoacoustic workflow in MPEG-4 AAC operates through several Model 2 derived stages:

1. Fast Fourier Transform (FFT) and Unpredictability Measure

The encoder runs an independent 2048-sample (or 1024-sample in newer low-delay profiles) Fast Fourier Transform (FFT) in parallel with the MDCT filterbank. For every spectral line, the model calculates the unpredictability index \(c(\omega)\) based on a second-order polynomial prediction of phase and magnitude from the preceding two frames. High unpredictability signifies noise-like content, which can mask higher levels of quantization noise than predictable, tonal content.

2. Signal-to-Mask Ratio (SMR) and Threshold Calculation

Using the tonality factor derived from unpredictability, the model interpolates between pure tone-masking-noise and noise-masking-tone threshold curves. It then convolves this energy distribution across the Bark scale using a psychoacoustic spreading function to account for masking between adjacent frequency bands.

3. Integration with Temporal Noise Shaping (TNS) and Window Switching

Psychoacoustic Model 2 in AAC interfaces directly with the encoder's block-switching engine. If the psychoacoustic analysis detects an abrupt rise in signal energy that would otherwise cause audible pre-echo artifacts, the model instructs the MDCT to switch from long windows (2048 samples) to eight short windows (256 samples). It also informs the Temporal Noise Shaping (TNS) module to shape quantization noise in the time domain when transient conditions exist within a single frame.

Production Implementations

While the ISO/IEC standard reference software provides an exact realization of the advanced AAC Psychoacoustic Model 2, modern production encoders—such as the Fraunhofer FDK-AAC, Apple CoreAudio AAC, and modern variants of FAAC—use proprietary derivatives. These modern engines refine Model 2's unpredictability and thresholding math to optimize processing speed while maintaining strict adherence to human auditory masking limits.
