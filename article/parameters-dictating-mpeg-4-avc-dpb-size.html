Parameters Dictating MPEG-4 AVC DPB Size

In MPEG-4 AVC (H.264) video coding, the Decoded Picture Buffer (DPB) size specifies the maximum memory allocated to hold decoded frames for reference and output reordering. The maximum DPB capacity is not a static number of frames across all streams; instead, it is dynamically determined by standard-defined Level limits, the spatial resolution of the video, and specific picture-coding structure parameters.

1. MaxDpbMbs (Level-Defined Buffer Limit)

The primary parameter dictating DPB size is MaxDpbMbs (Maximum Decoded Picture Buffer Size in Macroblocks), defined for each profile and level in Annex A of the MPEG-4 AVC specification. Each Level establishes a hard limit on total DPB storage capacity measured in standard 16x16 luma macroblocks (or total memory equivalent in bytes). Higher levels allocate significantly larger MaxDpbMbs values to accommodate either higher resolutions, more reference frames, or both.

2. Picture Size in Macroblocks (PicSizeInMbs)

The actual frame resolution of the encoded video directly determines how much of the DPB memory a single decoded picture consumes. The parameter PicSizeInMbs is calculated from the picture width and height in macroblocks:

\[\text{PicSizeInMbs} = \lceil \text{Width} / 16 \rceil \times \lceil \text{Height} / 16 \rceil\]

Because DPB capacity is bounded by total macroblock memory rather than a fixed frame count, decreasing the frame resolution for a given Level frees up buffer space to hold a greater number of reference pictures.

3. The DPB Capacity Formula

The maximum number of reference frames/pictures that a decoder must support for a specific stream is calculated using the relationship between MaxDpbMbs and PicSizeInMbs:

\[\text{MaxDPB} = \min\left(\left\lfloor \frac{\text{MaxDpbMbs}}{\text{PicSizeInMbs}} \right\rfloor, 16\right)\]

4. The 16-Frame Absolute Hard Cap

Regardless of how small the picture resolution (PicSizeInMbs) is relative to MaxDpbMbs, the MPEG-4 AVC standard imposes an absolute structural cap of 16 reference frames (or 32 reference fields). Even if the arithmetic yields a capacity greater than 16, the DPB size cannot exceed this limit.

5. Picture Coding Structure (Frame vs. Field Coding)

The picture structure dictates whether the DPB units are allocated as whole frames or individual fields:

  • Progressive / Frame Coding: Each decoded picture occupies one full frame buffer entry.
  • Interlaced / Field Coding: When coded as complementary field pairs or independent fields, each field counts as half of a frame buffer unit. The maximum number of reference fields is double the calculated frame capacity, up to a maximum of 32 reference fields.

6. Bit Depth and Chroma Subsampling

While baseline calculations assume 8-bit 4:2:0 chroma subsampling (where one macroblock corresponds to 384 bytes of luma and chroma data), extended profiles (such as High 10 or High 4:2:2) adjust the memory footprint per macroblock. When higher bit depths (10-bit, 12-bit) or expanded chroma formats (4:2:2, 4:4:4) are used, the total byte allocation scales accordingly to ensure memory usage conforms to the specified Level.
