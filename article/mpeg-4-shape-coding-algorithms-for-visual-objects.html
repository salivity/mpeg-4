MPEG-4 Shape Coding Algorithms for Visual Objects

The MPEG-4 standard introduced object-based video coding, allowing scenes to be composed of individual visual objects with arbitrary shapes rather than standard rectangular frames. To encode the boundaries and transparency of these arbitrary objects efficiently, MPEG-4 utilizes a dedicated set of shape coding tools divided primarily into binary shape coding and grayscale (alpha) shape coding. This article outlines the specific algorithms and techniques MPEG-4 employs to compress both lossless and lossy shape information.

Binary Shape Coding

Binary shape coding defines whether a pixel is completely opaque (inside the object) or completely transparent (outside the object). The visual object mask is divided into 16x16 pixel blocks known as Binary Alpha Blocks (BABs). MPEG-4 classifies each BAB into one of three categories: all-transparent, all-opaque, or boundary (containing both transparent and opaque pixels). For boundary blocks, MPEG-4 applies the following algorithms:

  • Context-based Arithmetic Encoding (CAE): CAE is the primary entropy coding method for binary shapes. It predicts the state of the current pixel based on a defined structural template of neighboring pixels and encodes the result using arithmetic coding.
    • Intra-CAE: Uses a 10-pixel spatial context template from previously encoded pixels within the same frame to predict pixel values.
    • Inter-CAE: Utilizes temporal redundancy by combining a 9-pixel spatial context with a 5-pixel motion-compensated context from the reference frame to predict pixel values across time.
  • Shape Motion Vector (SMV) Prediction: To support Inter-CAE, MPEG-4 calculates dedicated motion vectors for shape boundaries, predicting how the object outline moves from frame to frame.
  • Lossy Shape Downsampling and Upsampling: For bandwidth-constrained applications, MPEG-4 allows downsampling the shape mask by a factor of 2 or 4. At the decoder side, the mask is upsampled and smoothed using an adaptive threshold filter to reconstruct the original boundaries with minimal distortion.

Grayscale (Alpha) Shape Coding

For visual objects that contain transparency gradients, anti-aliasing, or translucency (such as smoke, glass, or feathered edges), MPEG-4 employs grayscale shape coding (auxiliary alpha channels).

  • Standard DCT-based Alpha Coding: Grayscale alpha planes (ranging from 0 to 255) are treated similarly to luminance signals. The 16x16 blocks are divided into 8x8 sub-blocks, motion-compensated, and transformed using the standard Discrete Cosine Transform (DCT), followed by quantization and variable-length coding.

Boundary Handling and Texture Integration

To encode the texture (color and luminance) inside arbitrarily shaped regions, MPEG-4 uses specialized boundary adaptation algorithms:

  • Repetitive Padding and Low-Pass Extrapolation (LPE): When standard 8x8 DCT is used for texture coding, pixels located outside the arbitrary shape boundary are populated using iterative boundary pixel replication or low-pass extrapolation to minimize high-frequency artifacts at the edges.
  • Shape-Adaptive Discrete Cosine Transform (SA-DCT): Instead of padding, SA-DCT dynamically shifts active foreground pixels within an 8x8 block toward the top-left boundary. A 1D-DCT of variable length is applied vertically, followed by another 1D-DCT horizontally. This process compresses only the actual object pixels, optimizing coding efficiency without the overhead of dummy padded pixels.
