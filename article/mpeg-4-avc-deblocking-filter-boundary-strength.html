MPEG-4 AVC Deblocking Filter Boundary Strength

In MPEG-4 AVC (H.264), the deblocking filter automatically removes blocking artifacts caused by block-based transform and quantization processes. Central to this in-loop filtering mechanism is the Boundary Strength (\(bS\)) parameter, an integer value that determines how aggressively the filter should smooth the boundary between adjacent \(4\times4\) blocks. This article explains how the boundary strength parameter functions, how its values are assigned, and its role in balancing artifact reduction with edge preservation.

The Function of Boundary Strength (\(bS\))

During video compression, dividing frames into blocks creates artificial discontinuities along block edges. The MPEG-4 AVC deblocking filter evaluates every \(4\times4\) block boundary—both horizontally and vertically—and assigns a Boundary Strength value from 0 to 4.

The \(bS\) parameter acts as a control switch:

  • Determines filter activation: If \(bS = 0\), filtering is disabled for that specific edge.
  • Selects filtering intensity: Higher values (\(bS > 0\)) apply progressively stronger filtering algorithms to smooth out severe blocking artifacts.
  • Controls threshold limits: It sets the clipping parameters (\(\alpha\) and \(\beta\)) that prevent true image edges from being blurred.

How Boundary Strength Values Are Assigned

The encoder and decoder calculate \(bS\) using a strict decision tree based on the coding mode, motion vectors, and transform coefficients of the two adjacent blocks (Block \(p\) and Block \(q\)):

  • \(bS = 4\) (Strongest Filtering): Assigned to boundaries where at least one of the adjacent blocks is Intra-coded, and the boundary lies on the edge of a macroblock. This represents the highest likelihood of severe blocking artifacts.
  • \(bS = 3\) (Strong Filtering): Assigned when one of the adjacent blocks is Intra-coded, but the edge is inside a macroblock rather than on its perimeter.
  • \(bS = 2\) (Moderate Filtering): Assigned to Inter-coded blocks if either block contains non-zero residual transform coefficients, indicating high-frequency differences.
  • \(bS = 1\) (Light Filtering): Assigned to Inter-coded blocks that have no residual coefficients, but differ in reference frames, have different numbers of motion vectors, or possess motion vector disparities equal to or greater than one full luma sample.
  • \(bS = 0\) (No Filtering): Assigned when both blocks are Inter-coded, contain no transform coefficients, reference the same frame, and share virtually identical motion vectors. Because these blocks are spatially and temporally uniform, filtering is unnecessary.

Significance in Video Quality

By dynamically scaling from 0 to 4, the boundary strength parameter ensures that smoothing is applied only where compression artifacts are likely to appear. This conditional processing avoids over-blurring fine textures and sharp object contours while maintaining high visual quality and coding efficiency across varying bitrates.
