MPEG-4 Texture Coding Mathematical Transforms

This article provides an overview of the mathematical transforms utilized for texture coding in MPEG-4 visual objects. MPEG-4 Visual supports both traditional frame-based video and content-based, arbitrarily shaped visual objects. To compress the spatial texture and luminance/chrominance data of these objects efficiently, the standard primarily relies on three mathematical transforms: the standard Discrete Cosine Transform (DCT), the Shape-Adaptive Discrete Cosine Transform (SA-DCT), and the Discrete Wavelet Transform (DWT).

1. The 8x8 Discrete Cosine Transform (DCT)

The standard two-dimensional 8x8 Discrete Cosine Transform (2D-DCT) is the primary tool used for encoding rectangular video frames and fully opaque interior blocks within arbitrarily shaped visual objects.

  • Mechanism: It converts \(8 \times 8\) blocks of spatial-domain pixel data into frequency-domain coefficients.
  • Function: The 2D-DCT compacts the energy of the image into a few low-frequency coefficients located at the top-left of the transform matrix, allowing higher-frequency details to be heavily quantized and discarded without significant perceived loss in visual quality.
  • Usage: Applied to standard macroblocks in frame-based profiles and interior blocks of Video Object Planes (VOPs) that do not cross object boundaries.

2. Shape-Adaptive Discrete Cosine Transform (SA-DCT)

For arbitrarily shaped visual objects, boundary blocks contain both active object pixels and empty background areas. The Shape-Adaptive DCT is specifically designed to transform only the active pixels within these boundary blocks.

  • Mechanism: SA-DCT is computed using a sequence of variable-length 1D-DCT operations:
    1. Vertical 1D-DCT: Object pixels within each column of an \(8 \times 8\) block are shifted to the top and transformed using a 1D-DCT whose length matches the number of active pixels in that column.
    2. Horizontal 1D-DCT: The resulting vertical DC and AC coefficients are shifted to the left of each row and transformed using a horizontal 1D-DCT whose length matches the number of transformed coefficients in that row.
  • Function: It preserves the energy compaction properties of the DCT along arbitrary boundaries without requiring artificial pixel padding techniques, minimizing bitrate overhead at object edges.

3. Discrete Wavelet Transform (DWT)

The Discrete Wavelet Transform is utilized in the MPEG-4 Still Texture profile to encode static textures, mapped surfaces for 3D meshes, and still visual objects with spatial and quality scalability.

  • Mechanism: The DWT decomposes an input image into multi-resolution subbands (low-low, low-high, high-low, and high-high frequency bands) using filter banks, typically employing biorthogonal wavelets (such as the 9/3 or 5/3 filters).
  • Function: Unlike block-based DCT transforms, the DWT operates on entire visual regions or arbitrary segments without blocking artifacts. It allows bitstreams to be progressively decoded across multiple levels of detail and resolution.
