How to Extract H.264 Raw Stream from MP4

Extracting a raw H.264 elementary stream from an MPEG-4 (MP4) container involves demuxing the video track without re-encoding while converting the packet format from AVCC to Annex B. This article outlines the standard procedure and commands required to accomplish this lossless extraction using industry-standard command-line tools like FFmpeg and MP4Box.

Understanding the Container vs. Elementary Stream

MP4 containers store H.264 video data in the AVCC format, which prefixes each Network Abstraction Layer (NAL) unit with its length in bytes. Raw H.264 elementary streams (typically saved with .h264 or .264 extensions) generally use the Annex B byte-stream format, which separates NAL units using start codes (such as 00 00 00 01). Therefore, a proper extraction procedure requires both demuxing the stream and applying a bitstream filter to convert AVCC to Annex B.

Method 1: Using FFmpeg (Standard Approach)

FFmpeg is the most widely used tool for this task because it handles container demuxing and bitstream conversion in a single command.

  1. Verify the video track index: Run FFprobe to identify the video stream:

    ffprobe input.mp4

  2. Extract the raw stream: Execute the following command to copy the video stream, apply the bitstream filter, and discard the audio:

    ffmpeg -i input.mp4 -c:v copy -bsf:v h264_mp4toannexb -an output.h264

    Parameter breakdown:

    • -i input.mp4: Specifies the input file.
    • -c:v copy: Instructs FFmpeg to copy the video stream directly without re-encoding (ensuring 100% original quality and fast processing).
    • -bsf:v h264_mp4toannexb: Converts the length-prefixed NAL units (AVCC) into start-code-prefixed NAL units (Annex B).
    • -an: Strips audio tracks from the output.
    • output.h264: The destination file for the raw elementary stream.

Method 2: Using MP4Box (GPAC)

MP4Box is a dedicated tool for handling ISO Base Media files like MP4.

  1. Identify the track ID:

    MP4Box -info input.mp4

    Look for the Track ID assigned to the H.264/AVC video.

  2. Extract the raw track: Run the raw extraction command using the identified track ID (assuming Track ID 1):

    MP4Box -raw 1 input.mp4

    MP4Box automatically handles the extraction and creates a file named input_track1.h264 in the current working directory.

Verification

To verify that the resulting file is a valid raw elementary stream, analyze it using FFprobe:

ffprobe output.h264

The output should confirm the format as h264 (H.264 / AVC / MPEG-4 AVC / MPEG-4 part 10) without any container metadata or audio tracks attached.
