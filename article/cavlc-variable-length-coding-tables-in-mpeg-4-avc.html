CAVLC Variable Length Coding Tables in MPEG-4 AVC

Context-Adaptive Variable-Length Coding (CAVLC) is an entropy coding scheme in the MPEG-4 AVC (H.264) video compression standard designed to efficiently compress quantized transform coefficients. This article explains how CAVLC dynamically utilizes multiple Variable-Length Coding (VLC) tables, detailing how the detection of "Trailing Ones" and surrounding block statistics govern table selection to maximize compression efficiency.

Understanding Trailing Ones in CAVLC

After transformation and quantization, coefficients are ordered using a zig-zag scan. Because higher-frequency coefficients are typically quantized to zero or small values, the end of the non-zero coefficient sequence often consists of a series of \(\pm 1\) values. CAVLC defines these as Trailing Ones (\(T1s\)).

CAVLC caps the maximum number of recognized Trailing Ones at three (\(0 \le T1s \le 3\)). Any additional \(\pm 1\) coefficients occurring earlier in the scan sequence are treated as general non-zero coefficient levels rather than trailing ones.

The Role of Trailing Ones in coeff_token Coding

The first syntax element transmitted for a block of coefficients is the coeff_token. This single element jointly encodes two pieces of information:

  1. TotalCoeff: The total count of non-zero coefficients in the block (ranging from 0 to 16 for a \(4\times4\) block).
  2. TrailingOnes: The number of trailing \(\pm 1\) values (ranging from 0 to 3).

CAVLC provides four separate VLC tables for encoding coeff_token (Num-VLC0, Num-VLC1, Num-VLC2, and a 6-bit fixed-length code table). The table is adaptively selected based on a context parameter, \(nC\), derived from the number of non-zero coefficients in the already-coded left and upper neighboring blocks:

\[nC = \frac{\text{TotalCoeff}_{\text{Left}} + \text{TotalCoeff}_{\text{Top}} + 1}{2}\]

  • \(0 \le nC < 2\): Uses Num-VLC0 (favors low coefficient counts and low \(T1s\)).
  • \(2 \le nC < 4\): Uses Num-VLC1.
  • \(4 \le nC < 8\): Uses Num-VLC2.
  • \(nC \ge 8\): Uses the 6-bit Fixed-Length Coding table.

Because the coeff_token represents the combined state of TotalCoeff and TrailingOnes, higher numbers of trailing ones produce shorter code lengths within the chosen table, reflecting their high statistical probability.

Sign Coding for Trailing Ones

Because the magnitudes of trailing ones are already known to be \(1\), CAVLC encodes them with minimal overhead. Immediately following the coeff_token, only the sign of each trailing one is transmitted in reverse scan order using a single bit:

  • 0 indicates a positive sign (\(+1\)).
  • 1 indicates a negative sign (\(-1\)).

By using 1-bit sign flags, CAVLC bypasses full magnitude coding for up to three coefficients.

VLC Table Selection for Remaining Levels

Once the trailing ones are coded, the remaining non-zero coefficients (referred to as levels) are coded in reverse zig-zag scan order. CAVLC uses seven distinct variable-length tables for levels: VLC0 through VLC6 (where VLC0 to VLC5 use prefix/suffix Exp-Golomb-style codes, and VLC6 uses a fixed-length suffix).

The presence and count of Trailing Ones directly determine the initial VLC table used for the first remaining level:

  1. Initial Table Selection:

    • If \(\text{TotalCoeff} > 10\) and \(\text{TrailingOnes} < 3\), coding begins with VLC1.
    • In all other cases, coding begins with VLC0.
    • If \(\text{TrailingOnes} = 3\), the first non-zero level to be coded is guaranteed to have an absolute magnitude greater than 1. To account for this, CAVLC subtracts 1 from the magnitude before encoding, allowing smaller code words in VLC0.

  2. Adaptive Table Switching:

    • As levels are decoded from right to left, coefficient magnitudes typically increase. CAVLC adapts to this by switching to higher-indexed VLC tables (e.g., VLC0 \(\rightarrow\) VLC1 \(\rightarrow\) VLC2) when an encoded coefficient exceeds predefined thresholds for the current table.
    • The table index never decreases within a single block, maintaining optimal code allocation for the larger low-frequency coefficients coded last.
