MPEG-4 Deblocking Boundary Strength Calculation

The in-loop deblocking filter in MPEG-4 (specifically MPEG-4 Part 10 / H.264 AVC) eliminates blocking artifacts across \(4\times4\) block boundaries using an adaptive filtering algorithm. This article details the specific computational mechanism and conditional decision tree used to derive the Boundary Strength parameter, which governs the intensity of the filtering applied to horizontal and vertical block edges.

The Role of Boundary Strength

The Boundary Strength, denoted as \(bS\), is an integer value ranging from \(0\) to \(4\) assigned to every edge separating two adjacent \(4\times4\) sample blocks, denoted as block \(p\) (left/upper) and block \(q\) (right/lower). The value of \(bS\) determines whether filtering is bypassed (\(bS = 0\)), weakly applied (\(bS \in \{1, 2, 3\}\)), or strongly applied (\(bS = 4\)).

Computational Decision Hierarchy

The calculation of \(bS\) executes through a prioritized conditional evaluation tree based on block prediction modes, transform coefficient presence, reference frame indices, and motion vector differentials.

1. Intra-Prediction Evaluation (\(bS = 4\) and \(bS = 3\))

The computational engine first checks the macroblock coding mode for both adjacent blocks \(p\) and \(q\):

  • \(bS = 4\): Assigned if either block \(p\) or block \(q\) is Intra-coded and the edge between them coincides with a macroblock boundary. This invokes the strongest non-linear filtering profile.
  • \(bS = 3\): Assigned if either block \(p\) or block \(q\) is Intra-coded, but the edge is internal to the macroblock.

2. Residual Transform Coefficients (\(bS = 2\))

If neither block is Intra-coded, the mechanism checks for the presence of non-zero transform coefficients:

  • \(bS = 2\): Assigned if either block \(p\) or block \(q\) contains at least one non-zero transform coefficient (\(TotalCoeff > 0\)). This accounts for high-frequency residual quantization artifacts introduced during discrete cosine/integer transformation.

3. Motion Vector and Reference Index Differential (\(bS = 1\))

If both blocks are Inter-coded and neither contains residual transform coefficients, filtering necessity is derived from spatial motion discontinuities:

  • \(bS = 1\): Assigned if any of the following conditions evaluate to true:
    • Reference Frame Mismatch: Block \(p\) and block \(q\) use different reference frames, or a different total count of motion vectors (e.g., one block uses uni-directional prediction while the other uses bi-directional prediction).
    • Motion Vector Displacement: Both blocks use the same single reference picture, but the absolute difference between their motion vector components equals or exceeds one full luma sample. Because motion vectors are represented in quarter-pixel precision, the condition evaluates: \[\max(|MV_{p,x} - MV_{q,x}|, |MV_{p,y} - MV_{q,y}|) \ge 4\]
    • Dual Motion Vector Divergence: For bi-directionally predicted blocks with matching reference lists, motion vectors associated with the same reference picture pair diverge by \(\ge 4\) quarter-pixel units in either the horizontal or vertical axis.

4. Redundant Edge Bypass (\(bS = 0\))

  • \(bS = 0\): Assigned when neither block has residual coefficients, both share identical reference frames, and their motion vector difference is strictly below the one-sample threshold (\(|\Delta MV| < 4\)). Under this condition, no true physical edge artifact exists, and the filtering process is completely bypassed for that boundary segment.

Pipeline Integration

Once \(bS\) is computed, it serves as an index alongside the average Quantization Parameter (\(QP_{av} = (QP_p + QP_q + 1) \gg 1\)) to retrieve threshold variables \(\alpha(QP)\) and \(\beta(QP)\) from lookup tables. These thresholds, along with the determined \(bS\) value, establish the gradient thresholds required to differentiate between genuine image edges and blocking artifacts prior to sample modification.
