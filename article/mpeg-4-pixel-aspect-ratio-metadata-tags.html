MPEG-4 Pixel Aspect Ratio Metadata Tags

This article explains the metadata tags and box structures used to define Pixel Aspect Ratio (PAR) adjustments in standard MPEG-4 (MP4) containers. It covers container-level atoms defined by the ISO Base Media File Format as well as bitstream-level parameters within common MPEG-4 video codecs that govern non-square pixel rendering during playback.

Container-Level Metadata: The pasp Atom

In standard MPEG-4 Part 14 (MP4) files and ISO Base Media File Format (ISOBMFF) structures, the primary container-level metadata tag for defining pixel aspect ratio is the pasp (Pixel Aspect Ratio) box.

  • Hierarchy Location: moov > trak > mdia > minf > stbl > stsd > [sample_entry] > pasp
  • Parent Structure: The pasp box resides inside the visual sample entry (such as avc1, hev1, or mp4v) within the Sample Description table (stsd).
  • Core Fields:
    • hSpacing (32-bit unsigned integer): Specifies the horizontal spacing of pixels (numerator).
    • vSpacing (32-bit unsigned integer): Specifies the vertical spacing of pixels (denominator).

The pixel aspect ratio is defined by the ratio hSpacing:vSpacing. For example, a standard definition 16:9 anamorphic PAL video with a PAR of 16:11 sets hSpacing = 16 and vSpacing = 11.

Track Presentation Scaling: The tkhd Atom

While not strictly defining PAR as a standalone ratio, the tkhd (Track Header) box defines the intended display geometry of the video track.

  • Hierarchy Location: moov > trak > tkhd
  • Key Attributes: Contains 32-bit fixed-point (16.16) values for width and height, along with a 3x3 transformation matrix.
  • Function: Decoders scale the encoded pixel dimensions (stored in the visual sample entry) to match the presentation dimensions specified in the tkhd box.

Bitstream-Level Metadata

In addition to container-level atoms, MPEG-4 containers encapsulate video elementary streams that contain their own native PAR/SAR (Sample Aspect Ratio) metadata.

H.264 / MPEG-4 AVC (Advanced Video Coding)

Stored within the SPS (Sequence Parameter Set) under the VUI (Video Usability Information) parameters:

  • aspect_ratio_info_present_flag: Indicates presence of aspect ratio parameters.
  • aspect_ratio_idc: An 8-bit index identifying standard predefined aspect ratios (e.g., 1:1, 4:3, 16:9 PAL/NTSC).
  • sar_width and sar_height: 16-bit integers defining custom aspect ratios when aspect_ratio_idc is set to 255 (Extended_SAR).

H.265 / HEVC (High Efficiency Video Coding)

Stored similarly to AVC within the SPS:

  • vui_parameters_present_flag > aspect_ratio_info_present_flag
  • aspect_ratio_idc
  • sar_width and sar_height (used when aspect_ratio_idc equals Extended_SAR).

MPEG-4 Part 2 Visual

Stored within the VOL (Video Object Layer) header:

  • aspect_ratio_info: A 4-bit field designating standard aspect ratios.
  • par_width and par_height: 8-bit fields present when aspect_ratio_info is set to Extended PAR (1111).

Decoder Precedence

When container metadata (pasp) and elementary stream metadata (SPS/VUI) conflict, container parsers and decoders generally prioritize the pasp box to determine playback geometry. However, robust rendering pipelines verify consistency between both layers to prevent display distortion.
