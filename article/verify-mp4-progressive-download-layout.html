Verify MP4 Progressive Download Layout

To enable progressive download (often called "Fast Start" or web optimization), an MPEG-4 file must have its metadata container—the moov atom—positioned before the raw media data (mdat atom). This layout allows web browsers and media players to read the file's index immediately and begin playback before downloading the entire file. This article details the most reliable tools and methods to verify that an MP4 file is properly structured for progressive download, along with quick steps to fix it if it is not.

1. Verification Using FFprobe (FFmpeg)

FFprobe allows you to trace the exact order of atoms inside the MP4 container from the command line.

Run the following command:

ffprobe -v trace input.mp4 2>&1 | grep -E "type:'moov'|type:'mdat'"

Interpreting the Output:

  • Correct (Progressive Download Ready): The type:'moov' entry appears before the type:'mdat' entry in the terminal output.
  • Incorrect: The type:'mdat' entry appears before type:'moov'.

2. Verification Using MediaInfo

MediaInfo is a lightweight GUI and CLI utility that explicitly reports container metadata.

  • CLI Command:

    mediainfo --Inform="General;%IsStreamable%" input.mp4
    • If it returns Yes, the file is configured for progressive download.
    • If it returns No or blank, the moov atom is at the end of the file.

  • GUI Method: Open the file in MediaInfo, switch to the Tree or Text view, and inspect the General section for the property IsStreamable : Yes or Format settings : Web optimized.

3. Verification Using MP4Box (GPAC)

MP4Box can analyze the file's layout and hint structures.

Run the following command:

MP4Box -info input.mp4

Look for lines indicating file structure. If the file is properly optimized, MP4Box will report that the file is interleaved or that metadata is located at the beginning of the file.

4. Verification Using a Web Browser

You can test the real-world behavior of the file directly in a modern web browser:

  1. Open Google Chrome, Firefox, or Microsoft Edge.
  2. Open Developer Tools (F12) and navigate to the Network tab.
  3. Enable network throttling (e.g., set to "Fast 3G" or "Slow 3G").
  4. Drag and drop the MP4 file into the browser window or load it via a local web server using an HTML5 <video> tag.
  5. Result: If playback starts within a few seconds while the download progress bar is still filling, progressive download is functioning properly. If playback waits until 100% of the file is loaded, the layout is incorrect.

How to Fix an Incorrect Layout

If verification reveals that the moov atom is at the end of the file, you can relocate it to the front without re-encoding the video using FFmpeg:

ffmpeg -i input.mp4 -c copy -movflags +faststart output.mp4

This operation processes in seconds, shifts the moov atom to the beginning of output.mp4, and preserves the original audio and video quality.
