How MPEG-4 Compresses 3D Models Using 3DMC

This article provides an overview of how the MPEG-4 3D Mesh Coding (3DMC) standard compresses static 3D polygonal models. MPEG-4 3DMC drastically reduces the storage size and transmission bandwidth of 3D assets by decomposing a polygon mesh into its core components—connectivity, geometry, and photometric attributes—and applying specialized compression techniques to each. Through techniques such as Topological Surgery, differential predictive coding, quantization, and entropy coding, 3DMC delivers high compression ratios while preserving visual fidelity.

The Structure of a 3D Mesh

A standard 3D polygonal mesh consists of three primary data categories:

  1. Connectivity (Topology): Describes how vertices connect to form edges, faces, and polygons.
  2. Geometry: The 3D Cartesian coordinates \((x, y, z)\) defining the exact spatial position of each vertex.
  3. Attributes (Properties): Surface data such as normal vectors, texture coordinates \((u, v)\), and color values associated with vertices or faces.

MPEG-4 3DMC processes each of these components independently to maximize compression efficiency.

1. Connectivity Compression: Topological Surgery

Connectivity data typically accounts for a significant portion of uncompressed mesh files. MPEG-4 3DMC uses an algorithm known as Topological Surgery to compress this structure:

  • Cutting the Mesh: The algorithm makes a sequence of cuts along the edges of the 3D surface to convert an arbitrary manifold mesh into a simple, planar polygon without internal holes (a topological disk).
  • Vertex Graph and Triangle Tree: The cut path forms a spanning tree across the mesh vertices (the Vertex Graph), and the remaining connected faces form a spanning tree across the triangles (the Triangle Tree).
  • Run-Length Encoding: Both the Vertex Graph and the Triangle Tree are represented using simple planar graph properties and encoded as compact sequences of branch runs and leaf markers. This reduces the connectivity data to typically less than 2 bits per triangle.

2. Geometry Compression

Geometry data represents the physical coordinates of the model's vertices. 3DMC compresses geometry using a three-step pipeline:

Quantization

Vertex coordinates are converted from 32-bit floating-point values into fixed-point integers using a uniform bounding-box quantizer. Users can define the precision (e.g., 8 to 16 bits per coordinate), directly controlling the trade-off between file size and spatial accuracy.

Predictive Coding (The Parallelogram Rule)

Because adjacent vertices in a 3D mesh tend to be spatially close, 3DMC avoids storing raw coordinate values. Instead, it predicts the position of a new vertex based on already decoded adjacent triangles using the parallelogram rule:

  • If two adjacent triangles share an edge, the fourth vertex is predicted to complete a flat parallelogram with the first triangle.
  • The encoder computes a prediction error (residual) representing the difference between the actual quantized position and the predicted position.

Residual Quantization

The resulting prediction residuals are tightly clustered around zero, drastically reducing the dynamic range of the coordinate data.

3. Attribute Compression

Surface attributes like normal vectors, vertex colors, and texture mapping coordinates are compressed using methods analogous to geometry compression:

  • Normals: Transformed to spherical coordinates or local tangent frames, quantized, and predicted based on face orientations.
  • Texture Coordinates: Quantized and predicted across adjacent faces using 2D affine transformations.
  • Colors: Quantized in standard color spaces (such as RGB or YUV) and predicted across adjacent vertices.

4. Entropy Coding

The final stage of the 3DMC pipeline is lossless entropy coding. The sequences of connectivity commands, geometry prediction residuals, and attribute residuals are encoded using adaptive arithmetic coding. Because the prediction and topological steps concentrate data into predictable, low-entropy distributions, the arithmetic coder achieves near-optimal bit-rate efficiency.

Key Capabilities of 3DMC

  • High Compression Ratios: Achieves file size reductions between 90% and 98% compared to uncompressed formats like OBJ or raw VRML.
  • Hierarchical and Progressive Transmission: Supports scalable bitstreams where a low-resolution base mesh loads first, followed by successive refinement layers as bandwidth permits.
  • Error Resilience: Includes segmentation tools to packetize data for streaming over lossy networks without total model corruption.
