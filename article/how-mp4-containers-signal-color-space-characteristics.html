How MP4 Containers Signal Color Space Characteristics

MPEG-4 containers (MP4) define color representation using specialized metadata boxes that specify how video pixels should be interpreted and displayed. By utilizing the Color Information Box (colr) embedded within the sample description hierarchy, MP4 files explicitly signal color primaries, transfer characteristics (gamma/EOTF curves), matrix coefficients (RGB to YUV conversions), and dynamic range limits. This metadata ensures that media players and display devices render colors accurately across SDR, HDR, and wide color gamut standards.

The Color Information Box (colr)

The MP4 container format, derived from the ISO Base Media File Format (ISOBMFF), stores color space parameters inside the colr box. This box is nested within the video track's sample entry description structure:

moov → trak → mdia → minf → stbl → stsd → <visual_sample_entry> → colr

The visual sample entry corresponds to the video codec being used (such as avc1 for H.264, hvc1 for HEVC, or av01 for AV1).

The nclx Parameter Set

Within the colr box, the container specifies a colour_type four-character code. The modern standard for digital video is nclx (On-Screen Colour Parameters), which supersedes the legacy Apple nclc format.

The nclx payload contains four distinct fields:

  1. Colour Primaries (16-bit integer): Defines the chromaticity coordinates (CIE 1931 xy) of the red, green, and blue primary colors, as well as the reference white point. Common values include BT.709 (sRGB/HD standard) and BT.2020 (UHD/Wide Color Gamut).
  2. Transfer Characteristics (16-bit integer): Defines the opto-electronic transfer function (OETF) or electro-optical transfer function (EOTF) used to encode and decode luminance levels. This specifies the gamma curve for standard dynamic range (such as BT.709 or BT.601) or the HDR transfer curve (such as SMPTE ST 2084 / PQ, or ARIB STD-B67 / HLG).
  3. Matrix Coefficients (16-bit integer): Defines the mathematical transformation matrix used to derive luma and chroma signals (\(Y', C_b, C_r\)) from red, green, and blue (\(R', G', B'\)) inputs. Examples include BT.709 matrix for HD video, BT.601 for standard definition, and BT.2020 non-constant luminance matrix for UHD.
  4. Full Range Flag (1-bit integer): Indicates whether the color component values use full range quantization (0–255 for 8-bit, common in PC graphics and JPEG) or narrow/limited video range quantization (16–235 for luma and 16–240 for chroma, standard for broadcast and consumer video).

Standardization via ITU-T H.273 / CICP

The numerical values assigned to primaries, transfer characteristics, and matrix coefficients follow the standardized Coding-Independent Code Points (CICP) defined by ITU-T H.273 and ISO/IEC 23091-2.

For example, a typical 4K HDR10 video using the PQ transfer curve is signaled with:

  • Colour Primaries: 9 (ITU-R BT.2020)
  • Transfer Characteristics: 16 (SMPTE ST 2084 / PQ)
  • Matrix Coefficients: 9 (ITU-R BT.2020 non-constant luminance)
  • Full Range Flag: 0 (Limited range)

Container vs. Bitstream Signaling

Color characteristics can be signaled at two distinct layers:

  • The Container Layer (ISOBMFF/MP4): Stored in the colr box, allowing demuxers, parsers, and operating systems to determine the video's color properties without decoding the underlying video stream.
  • The Elementary Stream Layer (Bitstream): Stored directly inside codec-specific parameter sets, such as the Video Usability Information (VUI) within the Sequence Parameter Set (SPS) for H.264 and HEVC, or Sequence Header OBUs in AV1.

While standard-compliant decoders prioritize consistency between both layers, modern playback pipelines rely on the container-level colr box for fast pipeline configuration, hardware display synchronization, and correct color management before decoding starts.
