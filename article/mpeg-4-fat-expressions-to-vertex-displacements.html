MPEG-4 FAT: Expressions to Vertex Displacements

This article provides an overview of how MPEG-4 Facial Animation Tables (FAT) translate abstract facial control signals into 3D geometry changes. It details the step-by-step mechanism of taking high-level Facial Animation Parameters (FAPs), normalizing them using model-specific metrics, and applying table-driven interpolation functions to compute exact 3D vertex displacements on a facial mesh.

The MPEG-4 Facial Animation Framework

The MPEG-4 standard defines a compact, model-independent system for animating human faces using two core concepts:

  1. Facial Animation Parameters (FAPs): A set of 68 parameters representing high-level facial actions (such as opening the jaw, raising an eyebrow, or stretching the lips).
  2. Facial Definition Parameters (FDPs): The geometric definition of the 3D face model, including feature point locations and mesh topology.

Because different 3D face models have varying vertex densities and proportions, high-level FAP commands cannot directly specify raw 3D coordinates. Instead, the Facial Animation Table (FAT) serves as the decoder and mapping interface tailored to a specific 3D mesh.

Normalization via Facial Animation Parameter Units (FAPUs)

Before accessing the FAT, incoming FAP values are normalized using Facial Animation Parameter Units (FAPUs). FAPUs are fractional distances based on standard facial landmarks defined on the neutral face, such as:

  • IRISD0: Iris diameter.
  • ES0: Distance between the eye centers (eye separation).
  • ENS0: Distance between the nose base and the line connecting the eye centers.
  • MW0: Lip corner-to-corner mouth width.
  • MNS0: Distance between the nose base and the mouth center.

When a high-level command specifies a FAP value (e.g., jaw drop by \(X\) units), the engine scales this value by the corresponding FAPU to ensure proportional deformation regardless of face size.

Internal Structure of Facial Animation Tables

A Facial Animation Table is defined per model and contains an entry for every supported FAP. Each entry maps an incoming parameter intensity to explicit mesh alterations through the following data structure:

  • Target Vertices: A list of mesh vertex indices affected by the specific FAP.
  • Intervals and Keyframes: A series of input control values (breakpoints) that span the valid range of the FAP.
  • Displacement Vectors: 3D displacement offsets \((\Delta x, \Delta y, \Delta z)\) assigned to each target vertex at each breakpoint.

The Mapping and Interpolation Process

When a high-level FAP command is received, the MPEG-4 decoder executes the following sequence:

  1. Parameter Normalization: The incoming FAP value is multiplied by its respective FAPU to obtain an absolute scalar distance \(s\).
  2. Interval Matching: The engine checks the FAT entry to locate which defined interval contains the scalar value \(s\) (between two keyframes \(k_1\) and \(k_2\)).
  3. Piecewise Interpolation: For each vertex indexed in that FAT entry, the engine computes an interpolated displacement vector \(\vec{D}\) using piecewise linear or polynomial functions: \[\vec{D}_i(s) = \vec{D}_{i, k_1} + \frac{s - k_1}{k_2 - k_1} \left( \vec{D}_{i, k_2} - \vec{D}_{i, k_1} \right)\] Where \(\vec{D}_i(s)\) represents the calculated displacement for vertex \(i\).

Superposition and Final Mesh Reconstruction

A single facial expression typically activates multiple FAPs simultaneously (e.g., smiling while raising eyebrows). When multiple FAPs influence the same vertex:

  1. Displacements from all active FAPs affecting vertex \(i\) are computed independently via their respective FAT entries.
  2. The displacement vectors are summed linearly: \[\vec{V}_{i, \text{deformed}} = \vec{V}_{i, \text{neutral}} + \sum_{m \in \text{Active FAPs}} \vec{D}_{i, m}\]
  3. The resulting offset is added to the vertex's neutral position \(\vec{V}_{i, \text{neutral}}\), producing the final deformed 3D coordinate.

This architecture enables low-bandwidth transmission of expression data while maintaining the freedom to render complex, high-fidelity deformations on diverse 3D models.
