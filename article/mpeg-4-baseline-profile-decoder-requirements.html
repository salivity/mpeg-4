MPEG-4 Baseline Profile Decoder Requirements

To claim compliance with the MPEG-4 Baseline Profile (specifically under MPEG-4 Part 10 / H.264 AVC), a decoder must fully implement a standardized set of decoding tools, syntax elements, and error-resilience features without requiring high-complexity tools reserved for advanced profiles. Compliance guarantees that the decoder can accurately reconstruct video streams encoded within defined parameter limits and levels, ensuring interoperability across consumer hardware, mobile platforms, and communication networks.

Mandatory Slice and Coding Types

A compliant decoder must support specific slice types and spatial prediction modes:

  • Slice Types: Support for I-slices (Intra-coded) and P-slices (Predicted). Support for B-slices (Bi-directional predicted) and SP/SI slices is excluded.
  • Intra Prediction: Full decoding of spatial Intra-coding modes, including Intra_4x4, Intra_16x16, and corresponding chroma Intra-prediction (DC, Vertical, Horizontal, and Plane modes).
  • Color Format: Native decoding of standard 4:2:0 YCbCr planar chroma sampling.

Inter Prediction and Motion Compensation

The decoder must correctly interpret complex motion vector syntax:

  • Variable Block Sizes: Motion compensation support for partition sizes of 16x16, 16x8, 8x16, and 8x8, as well as sub-macroblock partitions (8x4, 4x8, and 4x4).
  • Sub-Pixel Precision: 1/4-pixel (quarter-pel) luma motion vector precision using 6-tap filtering for half-pel and bi-linear filtering for quarter-pel, along with 1/8-pixel chroma precision.
  • Multiple Reference Frames: Capability to store and select from multiple reference picture frames within the Decoded Picture Buffer (DPB).

Entropy Coding and Filtering

Baseline profile limits entropy complexity to ensure lightweight processing:

  • CAVLC: Mandatory decoding of Context-Adaptive Variable-Length Coding (CAVLC) and Exp-Golomb coded syntax elements. Support for CABAC (Context-Adaptive Binary Arithmetic Coding) is not required.
  • In-Loop Deblocking Filter: Implementation of the adaptive in-loop deblocking filter across 4x4 block edges to mitigate blocking artifacts.

Error Resilience Features

A standard Baseline Profile decoder must support specific network error-resilience mechanisms:

  • Arbitrary Slice Ordering (ASO): Ability to decode slices received out of sequence within a frame.
  • Flexible Macroblock Ordering (FMO): Capability to decode macroblocks allocated via slice groups rather than pure raster scan order.
  • Redundant Slices: Ability to identify, process, or discard redundant coded representations of primary slices.

(Note: If claiming compliance specifically with the Constrained Baseline Profile (CBP), support for FMO, ASO, and redundant slices is not mandatory, while maintaining all other Baseline capabilities.)

Level Compliance and Buffer Management

To claim compliance at a specific level (e.g., Level 1.0 to Level 5.1), the decoder must satisfy:

  • Throughput: Processing capability matching the specified Maximum Macroblock Processing Rate (MaxMBPS) and Frame Size (MaxFS).
  • Decoded Picture Buffer (DPB): Sufficient internal memory allocation to hold reference frames required by the target level.
  • Bitrate: Ability to parse and process video delivered at the maximum bit rate defined for that level.
