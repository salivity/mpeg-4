HDR Metadata in MPEG-4 AVC vs Newer Standards

High Dynamic Range (HDR) video delivery requires carrying specific colorimetric and luminance metadata alongside the encoded bitstream to ensure accurate rendering on capable displays. This article examines how the legacy MPEG-4 Advanced Video Coding (AVC / H.264) standard handles HDR metadata encapsulation compared to modern codecs like HEVC (H.265), VVC (H.266), and AV1. While MPEG-4 AVC relies on retrofitted Supplemental Enhancement Information (SEI) messaging and custom profiles to support basic HDR, modern standards feature native architectural support for both static and frame-accurate dynamic HDR metadata.

HDR Encapsulation in MPEG-4 AVC (H.264)

MPEG-4 AVC was originally designed for Standard Dynamic Range (SDR) video operating in 8-bit color depths. To accommodate HDR formats like HDR10 and Hybrid Log-Gamma (HLG), subsequent amendments introduced signaling mechanisms through the Video Usability Information (VUI) parameters and Supplemental Enhancement Information (SEI) messages.

  • VUI Color Description: AVC signals the color container via VUI fields, including colour_primaries (e.g., ITU-R BT.2020), transfer_characteristics (such as SMPTE ST 2084 / PQ or ARIB STD-B67 / HLG), and matrix_coefficients.
  • Static Metadata via SEI Messages: Static HDR metadata, defined by SMPTE ST 2086 and CTA-861.3, is injected into the AVC bitstream via specific SEI messages:
    • Mastering Display Colour Volume (MDCV): Carries the chromaticity coordinates of the mastering display and its maximum/minimum luminance values.
    • Content Light Level Information (CLL): Carries Maximum Content Light Level (MaxCLL) and Maximum Frame-Average Light Level (MaxFALL).
  • Limitations: AVC requires the High 10 Profile for 10-bit processing to avoid severe color banding in HDR content. However, hardware decoders for AVC High 10 are uncommon in consumer devices compared to standard 8-bit decoders. Furthermore, AVC has limited standardized provisions for dynamic HDR metadata formats, relying instead on proprietary encapsulation methods.

HDR Metadata in Modern Standards: HEVC, VVC, and AV1

Newer video coding formats were developed concurrently with the evolution of HDR, resulting in native, robust metadata carriage pipelines.

HEVC (H.265)

HEVC serves as the baseline standard for commercial HDR10 and HLG distribution.

  • Standardized Profiles: The Main 10 profile is standard across nearly all modern hardware decoders, guaranteeing 10-bit support.
  • Dynamic Metadata Standardization: In addition to static MDCV and CLL SEI messages, HEVC natively standardizes dynamic metadata payloads (SMPTE ST 2094-10, ST 2094-40 for HDR10+, and Dolby Vision carriage via custom RPU SEI messages), enabling frame-by-frame or scene-by-scene tone mapping instructions.

VVC (H.266)

Versatile Video Coding refines the metadata structure of HEVC:

  • Enhanced Signaling: VVC expands the syntax in the Sequence Parameter Set (SPS) and VUI, reducing redundant metadata carriage across video streams.
  • Integrated Metadata Types: VVC natively accommodates multi-layer HDR signaling, wide color gamuts, and high-precision color remapping functions directly within its core specification.

AV1 (AOMedia Video 1)

AV1 handles metadata through Open Bitstream Units (OBUs) rather than legacy SEI messages:

  • Metadata OBUs: Static metadata (MDCV, CLL) and dynamic metadata (such as HDR10+ and proprietary formats) are encapsulated in dedicated OBU_METADATA packets.
  • Streamlined Parsing: Decoders can extract and process HDR tone-mapping parameters directly from the OBU structure without parsing low-level video payload slices, improving processing efficiency.

Technical Comparison Summary

  • Bit-Depth Native Support: Modern standards mandate 10-bit decoding pipelines in their primary profiles, whereas AVC limits 10-bit decoding to specialized, rarely hardware-accelerated profiles.
  • Dynamic Range Precision: AVC is constrained primarily to static parameters (single global values for the entire stream). Modern codecs seamlessly encapsulate dynamic per-frame tone-mapping data (SMPTE ST 2094 standards).
  • Parser Architecture: Modern codecs separate metadata extraction from sequence reconstruction via standardized metadata layers (HEVC SEI extensions, VVC parameter sets, and AV1 OBUs), ensuring higher transmission efficiency and reduced overhead compared to retrofitted AVC bitstreams.
