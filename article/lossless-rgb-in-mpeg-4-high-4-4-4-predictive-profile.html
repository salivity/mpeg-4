Lossless RGB in MPEG-4 High 4:4:4 Predictive Profile

The MPEG-4 AVC (H.264) High 4:4:4 Predictive Profile provides native support for lossless RGB color coding by combining full-resolution color sampling, residual color transforms, and a dedicated transform bypass mode. This article explains the technical mechanisms the profile uses to eliminate spatial, temporal, and inter-channel redundancy without discarding any visual data, ensuring mathematically lossless RGB video reproduction.

Full Resolution 4:4:4 Color Sampling

Standard video profiles use chroma subsampling (such as 4:2:0 or 4:2:2) to reduce file size by discarding color information that the human visual system is less sensitive to. The High 4:4:4 Predictive Profile preserves all color detail by sampling each color component—Red, Green, and Blue—at full spatial resolution. Every pixel retains its discrete, uncompromised color coordinates, which is essential for computer graphics, medical imaging, and professional video editing.

Transform and Quantization Bypass

In lossy H.264 compression, the encoder applies an integer Discrete Cosine Transform (DCT) followed by quantization, which intentionally discards high-frequency details.

To achieve true lossless coding, the High 4:4:4 Predictive Profile introduces a transform bypass mode (enabled via the qpprime_y_zero_transquant_bypass_flag). When activated:

  • The forward and inverse transform stages are bypassed.
  • Quantization is disabled entirely.
  • The in-loop deblocking filter is bypassed to prevent pixel smoothing.

Instead of quantizing transform coefficients, the encoder routes the raw prediction residual values directly to the entropy coder (CABAC or CAVLC), preserving the exact mathematical values of the original source.

Inter-Plane and Residual Color Transform

RGB video channels exhibit significant cross-color correlation; a change in the red channel is often mirrored in the green and blue channels. The High 4:4:4 Predictive Profile addresses this redundancy through an adaptive, reversible color transform known as YCoCg-R (or residual inter-plane prediction).

  1. Reversible Integer Arithmetic: Unlike standard RGB-to-YCbCr conversions that introduce rounding errors, the YCoCg-R transform uses simple integer additions, subtractions, and bit shifts.
  2. De-correlation: The transform converts RGB residuals into luminance (Y) and offset chrominance (Co - Orange, Cg - Green) components, expanding the dynamic range by only one bit to maintain complete mathematical reversibility.
  3. Adaptive Application: The encoder can adaptively decide on a block-by-block basis whether to apply the color space conversion or code the RGB residual planes independently, maximizing compression efficiency.

Predictive Coding for Lossless Residuals

Even in lossless mode, the profile takes full advantage of advanced predictive coding tools:

  • Intra Prediction: Predicts current block pixels from adjacent reconstructed pixels within the same frame using spatial prediction modes.
  • Inter Prediction: Utilizes motion vectors and reference frames to predict movement across frames.

Because the predictions are subtracted from the original input without quantization error, the resulting residuals represent the exact difference. These integer residuals are losslessly compressed using Context-Adaptive Binary Arithmetic Coding (CABAC), yielding substantial file size reductions while retaining an exact, bit-for-bit reconstruction of the original RGB source.
