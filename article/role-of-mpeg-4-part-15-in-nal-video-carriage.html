Role of MPEG-4 Part 15 in NAL Video Carriage

MPEG-4 Part 15 (formally ISO/IEC 14496-15) plays a foundational role in modern digital video delivery by standardizing the carriage mechanisms for Network Abstraction Layer (NAL) unit structured video within the ISO Base Media File Format (ISOBMFF) family. It defines how compressed video data from advanced codecs—including AVC (H.264), HEVC (H.265), and VVC (H.266)—is encapsulated, signaled, and organized within container formats like MP4. By establishing a uniform method to handle length-delimited NAL units, parameter sets, and multi-layer tracks, MPEG-4 Part 15 bridges raw codec bitstreams and container storage, enabling seamless file playback and streaming interoperability across platforms.

Bridging the Codec and Container Layer

Video codecs that utilize NAL unit architecture format their output into packets designed to be resilient across varied network and storage environments. However, the raw bitstream definitions (such as the Annex B byte stream format using 0x000001 or 0x00000001 start codes) are not optimized for random access, seeking, or metadata synchronization within media containers.

MPEG-4 Part 15 addresses this by standardizing an explicit encapsulation scheme. Instead of start codes, Part 15 specifies a length-prefixed mechanism where each NAL unit is preceded by a configured byte-length indicator (typically 1, 2, or 4 bytes). This structure allows parsers to immediately calculate the byte offset of the next NAL unit, optimizing demuxing performance and reducing parsing overhead.

Parameter Set Management

NAL-structured codecs rely heavily on Sequence Parameter Sets (SPS), Picture Parameter Sets (PPS), and Video Parameter Sets (VPS) to convey critical decoding instructions such as resolution, chroma format, and bit depth. MPEG-4 Part 15 specifies two distinct carriage modes for these parameter sets:

  1. Out-of-Band Carriage (Sample Entries): Parameter sets are placed directly inside the track's sample entry box (such as avcC for AVC or hvcC for HEVC) in the file header (moov box). This method ensures that the decoder receives configuration parameters prior to processing video samples, preventing mid-stream parsing errors and optimizing static file playback.
  2. In-Band Carriage (Sample Data): Parameter sets can also be carried directly within the media samples. This is essential for fragmented streaming workflows (like DASH and HLS), adaptive bitrate switching, and live broadcasts where configurations may update dynamically during a session.

Multi-Codec and Layered Video Support

As video compression technologies evolved, MPEG-4 Part 15 expanded to support successive generations of NAL-based codecs:

  • Advanced Video Coding (AVC / H.264): Defined the foundational avc1 and avc2 sample formats.
  • High Efficiency Video Coding (HEVC / H.265): Added specifications for hvc1 and hev1, supporting features like temporal sub-layers and tile tracks.
  • Versatile Video Coding (VVC / H.266): Introduced vvc1 and vvi1 carriage profiles.
  • Layered and 3D Extensions: Part 15 defines carriage for Scalable Video Coding (SVC), Multiview Video Coding (MVC), and Layered HEVC (L-HEVC), establishing track references to link base and enhancement layers efficiently.

Streaming and Fragmented MP4 Architecture

MPEG-4 Part 15 provides the exact rules required for fragmenting NAL unit structured video into Common Media Application Format (CMAF) chunks, fragmented MP4 (fMP4) segments, and ISO-BMFF-based adaptive streaming containers. By prescribing sample structure, sync sample identification (IDR/CRA frames), and composition time offsets, Part 15 ensures that media engines can perform frame-accurate seeking, smooth bitrate switching, and low-latency chunk demuxing.
