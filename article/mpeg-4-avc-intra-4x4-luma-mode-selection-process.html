MPEG-4 AVC Intra 4x4 Luma Mode Selection Process

MPEG-4 AVC (H.264) determines the best directional intra-prediction mode for 4x4 luma blocks through a mathematical decision process known as Rate-Distortion Optimization (RDO). The encoder evaluates nine possible prediction modes by projecting edge samples from previously decoded adjacent blocks, calculating the resulting residual error, and factoring in the bit cost required to signal the selected mode. The mode that minimizes the combined cost of visual distortion and bit consumption is chosen for the final encoding.

The 4x4 Luma Intra-Prediction Modes

For a 4x4 luma block, the encoder utilizes up to 13 neighboring reconstructed samples (labeled A through M) located directly above, above-right, and to the left of the target block. Using these samples, AVC defines nine distinct modes:

  • Mode 0 (Vertical): Extrapolates upper samples vertically downward.
  • Mode 1 (Horizontal): Extrapolates left-hand samples horizontally to the right.
  • Mode 2 (DC): Fills the block with the arithmetic mean of the available upper and left samples.
  • Mode 3 (Diagonal Down-Left): Extrapolates samples along a 45-degree angle pointing down and to the left.
  • Mode 4 (Diagonal Down-Right): Extrapolates samples along a 45-degree angle pointing down and to the right.
  • Mode 5 (Vertical-Right): Extrapolates samples diagonally downward and to the right at roughly 26.6 degrees off the vertical.
  • Mode 6 (Horizontal-Down): Extrapolates samples diagonally downward and to the right at roughly 26.6 degrees off the horizontal.
  • Mode 7 (Vertical-Left): Extrapolates samples diagonally downward and to the left at roughly 26.6 degrees off the vertical.
  • Mode 8 (Horizontal-Up): Extrapolates samples diagonally upward and to the right at roughly 26.6 degrees off the horizontal.

The Decision Workflow

The encoder selects among these nine modes using the following sequence:

1. Availability Check

The encoder determines which neighboring samples (A–M) are physically available within the current slice boundary. If a block borders a frame or slice boundary, modes requiring unavailable neighboring pixels are eliminated from consideration. If no neighbors are available, only DC prediction with a nominal value (such as 128 for 8-bit depth) is permitted.

2. Predictor Generation

For every valid mode, the encoder builds a 4x4 predictive block using the designated linear interpolation formulas specified by the H.264 standard.

3. Residual and Distortion Calculation

The encoder computes the difference between the original 4x4 source block and the generated predictor block to produce a residual block. Distortion (\(D\)) is quantified using one of several metrics depending on the encoder's complexity settings:

  • Sum of Absolute Differences (SAD): A low-complexity comparison of pixel differences.
  • Sum of Absolute Transformed Differences (SATD): Measures difference after applying a low-complexity transform (like the Hadamard transform) to approximate frequency-domain distortion.
  • Sum of Squared Errors (SSE): Full reconstruction error measured after transform, quantization, and inverse operations.

4. Mode Signaling Cost Estimation (Rate)

The encoder estimates the number of bits (\(R\)) needed to signal the mode in the bitstream. AVC uses context from the left and top adjacent blocks to determine a Most Probable Mode (MPM). If the candidate mode matches the MPM, it can be signaled with a single bit. If it does not, a 3-bit code is required to specify one of the remaining non-probable modes.

5. Lagrangian Cost Evaluation and Selection

The encoder calculates the final Rate-Distortion Cost (\(J\)) for each candidate mode using the Lagrangian equation:

\[J = D + \lambda \cdot R\]

Where:

  • \(D\) is the measured distortion.
  • \(R\) is the estimated bit rate required to encode the prediction mode and residual.
  • \(\lambda\) (lambda) is the Lagrange multiplier derived from the Quantization Parameter (QP).

The encoder compares the calculated \(J\) values across all valid candidate modes. The mode yielding the lowest total cost \(J\) is selected as the optimal intra-prediction mode for the 4x4 luma block.
