How MP4 Distinguishes Subtitles and Captions

The MPEG-4 (MP4) container format differentiates between timed text subtitles and closed caption bitstreams through a combination of box-level metadata, track handler types, sample descriptions (FourCC codes), and stream delivery methods. While timed text subtitles are generally stored in independent subtitle tracks, closed captions can exist either as discrete tracks or multiplexed directly within the video stream's bitstream. Demuxers and media players parse these specific structural elements in the ISO Base Media File Format (ISOBMFF) to identify, decode, and render each format appropriately.

1. Handler Types in the hdlr Box

Every track (trak) in an MP4 container includes a Handler Reference Box (hdlr) that specifies the nature of the media data:

  • Timed Text Subtitles: Typically use the handler type sbtl (subtitle) or text (general text).
  • Closed Captions: Standalone closed caption tracks typically use the handler type clcp (closed captions) or sbtl paired with caption-specific sample descriptions.
  • Embedded Captions: When captions are carried directly inside the video stream, the handler type remains vide, and the captions are discovered at the codec layer rather than the container handler level.

2. Sample Description Entries (stsd Box)

Inside the Sample Table Box (stbl), the Sample Description Box (stsd) uses distinct FourCC (Four-Character Code) identifiers to declare the exact coding format of the track samples:

  • Timed Text Formats:
    • tx3g: 3GPP Timed Text (MPEG-4 Part 17), the standard timed text format for MP4.
    • wvtt: WebVTT encapsulated in MP4 samples.
    • stpp: XML-based timed text (such as TTML or IMSC1).
  • Closed Caption Formats:
    • c608: CEA-608 (Line 21) closed caption bitstreams.
    • c708: CEA-708 digital closed caption bitstreams.

3. Track References (tref Box)

To distinguish accessibility closed captions from regular subtitle tracks, the container can define explicit relationships using the Track Reference Box (tref):

  • Closed caption tracks often contain a track reference of type cdsc (content describes). This establishes a formal link pointing to the primary video track that the captions describe.
  • General timed text subtitle tracks may omit this reference or use alternative references (such as subt) depending on the authoring standard.

4. Discrete Track vs. In-Band Bitstream Storage

The MP4 specification handles the transport architecture of these two data types differently:

  • Discrete Tracks (Out-of-Band): Timed text subtitles and discrete caption tracks (tx3g, c608, c708) have their own dedicated track IDs, time-to-sample boxes (stts), and chunk offset tables (stco/co64).
  • In-Band Video Embeddings: Closed captions (CEA-608/708) are frequently embedded directly within the video track's Elementary Stream as Supplemental Enhancement Information (SEI) NAL units (in AVC/H.264 or HEVC/H.265). In this scenario, the MP4 container treats the stream strictly as video, and the video decoder parses the SEI user data payload to extract the closed caption packets.
