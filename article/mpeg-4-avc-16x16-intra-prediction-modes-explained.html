MPEG-4 AVC 16x16 Intra Prediction Modes Explained

In MPEG-4 AVC (H.264), intra-prediction minimizes spatial redundancy within an individual video frame by predicting pixel values from neighboring, previously decoded boundary pixels. For smooth or homogeneous regions, the standard provides four distinct 16x16 luma intra-prediction modes: Vertical, Horizontal, DC, and Plane. Each mode applies a specific spatial interpolation method to reconstruct the 16x16 macroblock prior to residual coding.

Mode 0: Vertical Prediction

In Vertical mode, the encoder extrapolates the 16 decoded samples immediately above the current macroblock downward into every row. Each column within the 16x16 macroblock receives the value of the neighboring sample directly above it. This mode is selected when image features contain vertical stripes or vertical color consistency.

Mode 1: Horizontal Prediction

In Horizontal mode, the encoder extrapolates the 16 decoded samples immediately to the left of the current macroblock across every column. Each row within the 16x16 macroblock receives the value of the neighboring sample directly to its left. This mode is optimal for content exhibiting horizontal patterns or horizontal continuity.

Mode 2: DC Prediction

DC mode fills the entire 16x16 macroblock with a single, uniform average value derived from the adjacent upper and left boundary pixels. If both the upper and left neighbors are available, all 32 adjacent pixels (16 above, 16 left) are summed and averaged to form the DC value. If only the top or left boundary is available, the average is calculated using only the available set of 16 pixels. If neither boundary is available, a default value of 128 (for 8-bit video) is assigned to all pixels.

Mode 3: Plane Prediction

Plane mode fits a linear, two-dimensional spatial gradient across the 16x16 block using both the top and left adjacent reconstructed samples. The algorithm calculates horizontal and vertical slope parameters to generate a smooth, continuous transition across the macroblock. This mode is particularly effective for regions with gradual lighting variations, smooth shading, or tilted gradients.
